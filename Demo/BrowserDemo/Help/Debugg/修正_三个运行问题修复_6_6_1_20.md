# 修正指南

## 修正_三个运行问题修复_6_6_1_20

### focus
修复用户反馈的 3 个运行问题：AI 找不到作业却重复调用工具无输出、指引提示框操作后不自动删除、AI 回复不自动滚动到最下方

### reason
从日志 6-5-23-11-27.log 中分析发现：
1. **AI 重复调用工具无输出**：导航到 "您访问的页面不存在" 时返回 `Success()`，AI 以为页面正常；`wait_for_element` 忽略 selector 参数，不等待元素出现
2. **指引提示框不自动删除**：`StatusMessage` 在操作完成后持续显示，无自动清除机制
3. **不自动滚动到底部**：`MessageScroller` 在消息内容更新后不触发 `ScrollToBottom()`

### deepreason
1. `ExecuteNavigate` 的错误指示检测只写 `Logger.Warning`，不返回 `Fail()` → AI 不知道导航失败
2. `ExecuteWait` 的 `wait_for_element` 和 `wait_for_text` 混入 `wait_for_navigation` 的 case 块，仅检查 `document.readyState` → 页面已加载时立即返回成功，不等待元素
3. `AiChatPanel.xaml.cs` 的 `Loaded` 事件中未订阅 `StatusMessage` 变更和 `Messages.CollectionChanged` 事件

### solution
**修复 #A (P0)**：`ExecuteNavigate` 的错误检测将 `Logger.Warning` 改为 `return Fail(...)`
**修复 #B (P0)**：`ExecuteWait` 将 `wait_for_element`/`wait_for_text` 分离为独立 case，分别轮询元素存在性和文本存在性
**修复 #C (P1)**：`AiChatPanel.xaml.cs` 新增 5 秒 `DispatcherTimer` 自动清除 `StatusMessage`
**修复 #D (P1)**：`AiChatPanel.xaml.cs` 订阅 `Messages.CollectionChanged` 时自动滚动到底部

### change
涉及文件：

| 文件 | 变更内容 |
|------|---------|
| `Services/Automation/WebView2AutomationBridge.cs` | ExecuteNavigate: 错误指示检测从 Warning 改为 return Fail；ExecuteWait: 分离 wait_for_element(轮询 selector) 和 wait_for_text(轮询 innerText) |
| `Views/AiChatPanel.xaml.cs` | 新增 `_statusClearTimer`(5s DispatcherTimer) 自动清除 StatusMessage；订阅 Messages.CollectionChanged 自动 ScrollToBottom |

// ===== Fix A: 导航错误直接返回 Fail =====
foreach (var indicator in errorIndicators) {
    if (combinedText.Contains(indicator.ToLowerInvariant())) {
        Logger.Warning($"导航失败: 页面包含错误指示符 '{indicator}'");
        return Fail($"导航失败: 页面返回错误 — \"{pageTitle}\"");
    }
}

// ===== Fix B: wait_for_element 独立 case =====
case "wait_for_element":
    var exists = await ExecuteJsAsync(
        $"document.querySelector({JsonSerializer.Serialize(sel)}) !== null");
    if (exists == "true")
        return Success($"✅ 元素已出现: {sel}");
    // 否则轮询直到超时
    return Fail($"等待超时: 元素 '{sel}' 在 {timeoutMs}ms 内未出现");

// ===== Fix C: StatusMessage 5 秒自动清除 =====
_statusClearTimer.Tick += (_, _) => {
    if (_vm?.StatusMessage 不是错误/警告状态)
        _vm.StatusMessage = "";
    _statusClearTimer.Stop();
};

// ===== Fix D: 消息列表自动滚动 =====
_vm.Messages.CollectionChanged += (_, _) => {
    Dispatcher.BeginInvoke(() => MessageScroller?.ScrollToBottom());
};
