# 修正_新增ADB短信验证码获取技能_6_5_20_00.md

> focus ： 新增 skill_adb_sms 技能，通过 ADB 连接 Android 手机获取短信验证码支持网站手机号登录

> reason : 许多网站（闲鱼、转转、知乎等二手平台）要求手机号登录后才能进行后续操作，AI 搜索任务在登录环节卡住

> deepreason :
> 1. AI 在执行搜索任务时需要登录二手平台，但无法获取手机验证码
> 2. 用户手机上收到了验证码但浏览器内没有渠道获取
> 3. ADB（Android Debug Bridge）是最通用的跨平台手机数据访问方式，无需安装任何手机 App

> solution :
> 1. 创建 AdbService.cs —— 封装 adb 命令行交互，支持设备检查、短信读取、验证码等待
> 2. 提供双重短信获取策略：content://sms 数据库查询（主力）+ dumpsys notification 通知解析（降级）
> 3. 提供智能验证码等待：轮询 + 去重 + 发送方过滤 + 超时控制
> 4. 新增 BasicSkillDefinition SkillAdbSms 到技能注册表
> 5. 在 WebView2AutomationBridge 注册 ExecuteAdbSms 执行器
> 6. 同步更新所有技能计数、Schema 提示、函数文档

// AdbService.cs — 核心：通过 content://sms 查询短信数据库
public async Task<(bool, List<SmsMessage>, string?)> GetRecentSmsAsync(int limit, CancellationToken ct)
{
    var (ok, stdout, _) = await RunAdbAsync(
        $"shell content query --uri content://sms/inbox " +
        $"--projection address:body:date --sort \"date DESC\" --limit {limit}", ct);
    if (ok && !string.IsNullOrWhiteSpace(stdout))
        return (true, ParseSmsContentQuery(stdout), null);

    // 降级：dumpsys notification
    return ParseFromNotification();
}

// WebView2AutomationBridge.cs — 新增执行器
executor.RegisterBasicExecutor("skill_adb_sms", ExecuteAdbSms);
