# 修正_添加日志系统_6_3_22_30.md

> focus ： 为整个 Demo 项目添加后台控制台 CLI 输出日志和调试系统

> reason : 项目缺少统一的日志调试机制，排查问题困难

> deepreason : 所有类直接使用 Console.WriteLine 或完全无输出，无日志级别、无时间戳、无文件持久化、无函数追踪

> solution : 创建 Logger 全局静态服务类，基于 Win32 AllocConsole 实现后台控制台，支持：
> - 4 级日志（Debug/Info/Warning/Error）
> - 控制台彩色输出 + 文件持久化
> - 函数入口/出口追踪（using Trace 模式，含耗时）
> - OnLog 事件供 UI 实时显示
> - 在所有主要类中插入日志调用（MainWindow、ChatViewModel、AiClient、BrowserViewModel、ConversationService、AiSettingsDialog、ProviderManager）

```csharp
// Logger.cs 核心
public static void Write(LogLevel level, string message)
{
    var line = $"[{timestamp}][{levelStr}] {message}";
    // 控制台彩色输出
    if (_consoleAllocated) { Console.ForegroundColor = color; Console.WriteLine(line); }
    // 文件追加
    File.AppendAllText(LogFilePath, line + Environment.NewLine);
    // 事件通知
    OnLog?.Invoke(line);
}

public static IDisposable Trace(string signature)
{
    Write(LogLevel.Debug, $"> ENTER  {signature}");
    return new TraceBlock(signature);
}
// TraceBlock.Dispose → "< EXIT {sig} ({elapsed}ms)"
```
