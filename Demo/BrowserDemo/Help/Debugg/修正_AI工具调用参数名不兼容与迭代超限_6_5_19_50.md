# 修正_AI工具调用参数名不兼容与迭代超限_6_5_19_50.md

> focus ： 修正 AI 工具调用因参数名不兼容导致迭代超限且未产出最终答案

> reason : AI（DeepSeek V4 Flash）在执行搜索任务时使用了错误的参数键名（`element`、`css_selector`），而 WebView2AutomationBridge 只识别 `selector`

> deepreason : 
> 1. BasicSkillDefinition::ToToolDefinition() 生成的 `params` 字段为 `{type: "object"}`，未定义子属性的 JSON Schema，AI 收到后自行推测参数名（`element`、`css_selector`、`target` 等）
> 2. WebView2AutomationBridge 只硬编码匹配 `selector` 键名，其余别名均返回空字符串导致 Fail("缺少 selector 参数")
> 3. ExecuteConversationAsync 默认 25 轮迭代但搜索多平台的典型任务需 25-35 轮
> 4. AI 缺乏「即将超限应总结」的机制，在 35 轮用完时仍请求新工具调用而非给出答案

> solution :
> 1. WebView2AutomationBridge::GetSelector() — 扩展参数名识别：selector > css_selector > element > target > id > query > css，外加模糊推断（匹配 # . [ 开头字符串）
> 2. WebView2AutomationBridge::Fail() — 错误消息包含参数名提示，指导 AI 下次使用正确键名
> 3. BasicSkillDefinition::ToToolDefinition() — 为 8 个核心技能生成显式 params properties（type + description），并在 description 尾部追加 ⚡ 参数提示
> 4. AiClient::ExecuteConversationAsync() — 剩余 ≤5 轮时自动注入 System 消息提醒 AI 立即总结，≤2 轮时升级为紧急提醒
> 5. AiClient::ParseStreamRichAsync() — 增加 30s SSE 读取超时保护，防止服务器静默断开导致永久阻塞
> 6. maxIterations 从 25 提升到 35

// WebView2AutomationBridge.cs — GetSelector() 多别名 + 模糊推断
private static string GetSelector(Dictionary<string, object?> subParams, Dictionary<string, object?> parameters)
{
    foreach (var key in new[] { "selector", "css_selector", "element", "target", "id", "query", "css" })
    {
        var val = GetParam<string>(subParams, key) ?? GetParam<string>(parameters, key);
        if (!string.IsNullOrWhiteSpace(val)) return val;
    }
    // 模糊推断：匹配以 # . [ 开头且非 URL 的字符串值
    foreach (var dict in new[] { subParams, parameters })
        foreach (var (key, val) in dict)
            if (val is string s && !string.IsNullOrWhiteSpace(s)
                && (s.StartsWith("#") || s.StartsWith(".") || s.StartsWith("[") || s.Contains(">"))
                && !s.StartsWith("http") && s.Length < 500)
                return s;
    return "";
}

// AiClient.cs — 迭代上限预警
if (remaining <= 5 && remaining > 0)
{
    var urgency = remaining <= 2 ? "⚠️ 紧急" : "💡 注意";
    var warnMsg = $"{urgency}：还剩 {remaining} 轮工具调用机会，请立即基于已收集的数据给出最终答案...";
    messages.Add(new ChatMessage { Role = MessageRole.System, Content = warnMsg });
}
