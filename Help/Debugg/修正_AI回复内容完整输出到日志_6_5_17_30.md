focus: 将AI回复内容完整输出到日志端
reason: 用户要求AI的完整回复内容（而非截断的预览）输出到日志文件和控制台，便于调试和回溯
deepreason: 原有日志仅在成功时输出截断到100字符的预览("AI 回复预览: ...")，完整内容只存在于UI消息列表中，不持久化到日志。流式传输过程中也完全没有实时日志，无法追踪回复的生成过程
solution: 
  1. 用户输入改为完整输出到 Info 日志（不再截断60字符）
  2. 流式传输中每收到一个chunk，Debug 日志输出其内容和长度
  3. AI回复完成后，将完整内容输出到 Info 日志（前后加分隔线标记）
  4. 错误发生时，完整输出错误信息到 Error 日志
change:
  - 修改: ViewModels/ChatViewModel.cs
    - Logger.Info($"用户输入: {text}") — 完整输入
    - Logger.Debug($"AI回复流 chunk#{n}: +{len}字符 → \"{chunk}\"") — 每块流式日志
    - Logger.Info($"AI回复累计 (N字符) +"新增内容"")  + Logger.Info($"   内容: {currentContent}") — 每500ms输出一次累计内容
    - Logger.Error(errMsg) — 完整错误信息
keychangecode: {
  // 流式chunk日志
  Logger.Debug($"  AI回复流 chunk#{chunkCount}: +{chunk.Length} 字符 → \"{chunk}\"");

  // 流式累计日志 Info：每 500ms 输出累计内容
  if (lastInfoLog.ElapsedMilliseconds >= infoLogIntervalMs) {
    Logger.Info($"  AI回复累计 ({currentContent.Length}字符){newPart}");
    Logger.Info($"    内容: {currentContent}");
    lastInfoLog.Restart();
  }
}
