**focus**：修正全部标签关闭后重新打开收藏标签时的 WebView2 生命周期缺失和异常退出

**reason**：全部标签关闭后（ActiveTab = null），用户点击书签触发 `OpenBookmark` → `AddNewTab(url)`。旧版 `MainWindow` 依赖 `OnVmPropertyChanged(ActiveTab)` → `OnTabActivated` 来创建 WebView2，但这仅在 `ActiveTab` 属性变化时触发。具体来说：

1. `OpenBookmark` 在 `ActiveTab == null` 时调用 `AddNewTab(url)`，后者设置 `ActiveTab = tab` → 触发 `OnVmPropertyChanged(ActiveTab)` → `OnTabActivated(id)` → 检查到 WebView2 不存在 → 创建 WebView2。**这在响应式流程中看似可以工作**，但依赖于 async void 事件链，且 `OnTabActivated` 内的 `await EnsureTabWebViewAsync` 是异步的——在 `CollectionChanged` 事件和切换 UI 的过程中，时序竞态可能导致导航按钮等操作在 WebView2 创建完成前就已触发并崩溃。

2. 更关键的：如果 `OpenBookmark` 在 `ActiveTab != null` 时执行（非书签书签重新导航），它直接调用 `NavigateRequested` 而不创建标签——旧代码在 `ActiveTab != null` 且 WebView2 已销毁时同样缺少创建 WebView2 的保障。

3. 此外，`OnTabClosed` 的 `async void` 中如果 `CloseTabAsync` 抛出异常（例如 WebView2 已在 Dispose 中的操作），整个异常会不可捕获地逃逸到 WPF 消息泵，导致程序异常退出且没有任何日志记录。

**deepreason**：`MainWindow` 的 Tabs 生命周期缺少两条保障：
  1. 新标签加入 `Tabs` 集合时没有主动创建 WebView2 的钩子，完全依赖 `ActiveTab` 属性的被动通知；
  2. 标签关闭的 `async void` 事件处理器缺少 `try-catch` 包裹。

**solution**：
  1. 在 `Tabs.CollectionChanged` 中订阅 `Add` 事件，一旦新标签加入就主动调用 `EnsureAddedTabWebViewAsync(tab)`，不再依赖被动 `ActiveTab` 变化通知；
  2. 将 `OnTabClosed` 中 WebView2 清理操作包入 `try-catch` 并捕获异常到日志；
  3. 在 `App.OnStartup` 中注册三个全局未处理异常处理器（`DispatcherUnhandledException`、`AppDomain.UnhandledException`、`TaskScheduler.UnobservedTaskException`），确保异常不会逃逸且能写入日志。

**change**：
  - `MainWindow.xaml.cs`：`CollectionChanged` 闭包、`EnsureAddedTabWebViewAsync(TabInfo)` 方法、`OnTabClosed(Guid)` try-catch
  - `App.xaml.cs`：全局异常处理器注册与反注册
  - `Help/FunctionHelp.md`：新增函数文档
  - `Help/EffectHelp.md`：新增功能模拟

**keychangecode**：

```csharp
// MainWindow.xaml.cs — CollectionChanged 订阅新标签自动创建 WebView2
_vm.Tabs.CollectionChanged += (_, args) =>
{
    Logger.Debug($"Tabs 集合变化: {args.Action} → 共 {_vm.Tabs.Count} 个标签");
    UpdateTabCount();

    if (args.NewItems != null)
    {
        foreach (var item in args.NewItems)
        {
            if (item is TabInfo tab)
                _ = EnsureAddedTabWebViewAsync(tab);
        }
    }
};

// MainWindow.xaml.cs — OnTabClosed 异常保护
private async void OnTabClosed(Guid id)
{
    using var _ = Logger.Trace($"MainWindow::OnTabClosed({id})");
    try
    {
        if (_browserHost != null && _browserHost.GetWebViewForTab(id) != null)
            await _browserHost.CloseTabAsync(id);
    }
    catch (Exception ex)
    {
        Logger.Exception($"关闭标签 {id} 的 WebView 失败", ex);
        _vm.StatusText = $"标签关闭失败：{ex.Message}";
    }
    finally
    {
        UpdateTabCount();
    }
}

// App.xaml.cs — 全局异常兜底
AppDomain.CurrentDomain.UnhandledException += OnUnhandledException;
DispatcherUnhandledException += OnDispatcherUnhandledException;
TaskScheduler.UnobservedTaskException += OnUnobservedTaskException;
```
