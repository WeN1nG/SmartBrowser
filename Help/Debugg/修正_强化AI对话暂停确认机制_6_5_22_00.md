# 修正指南

## 修正_强化AI对话暂停确认机制_6_5_22_00

### focus
强化 AI 对话功能，使其可以在关键节点暂停向用户询问接下来的方向

### reason
原有设计（DESIGN.md §3.4 + §7.3）中，AI 工具调用循环是完全单向自主的：用户发送一条消息，AI 自动跑完最多 25 轮工具调用后一次性输出所有结果。这导致 AI 在遇到"岔路口"（如多个候选项需要选择、方案不确定需要确认）时只能自行猜测方向，用户完全没有介入机会。

### deepreason
IAiOrchestrator.SendMessageAsync() 的 IAsyncEnumerable<AiEvent> 是一个单向输出流，缺少"暂停-恢复"的双向交互通道。AI 的 ask_user 工具虽然可以在 ToolExecutor 中执行，但执行后如何暂停整个循环、如何等待用户输入、如何将用户回答作为 tool_result 回传给 AI 继续循环——这一整套机制在原设计中缺失。

### solution
1. **新增 ask_user 工具**：第 43 个工具，属于"用户交互"类别，AI 在需要用户指引时调用
2. **修改 AiEvent / AiEventType**：新增 UserQuestion、AwaitingUserInput 两种事件类型，新增 UserQuestionInfo 记录
3. **修改 IAiOrchestrator**：
   - 新增 RespondToQuestionAsync() 方法——接收用户回答并恢复执行流
   - 新增 IsAwaitingUserInput 属性——标记当前是否在暂停
   - 新增 CurrentQuestion 属性——提供当前问题信息给 UI
4. **修改状态机**：在 PARSE_RESP 后新增 ASK_USER 分支 → AWAITING_USER_INPUT → 用户回复 → USER_RESPONSE → 返回循环
5. **新增 AiPanelViewModel 交互方法**：SelectOptionAsync()、SubmitCustomResponseAsync()
6. **新增 AiChatPanel 问题卡片 UI 控件**：支持 confirmation/multiple_choice/open_ended 三种交互模式
7. **更新 P3/P4 实施计划**：P3 增加 ask_user 处理和 RespondToQuestionAsync 实现，P4 增加问题卡片 UI

### keychangecode
```csharp
// ===== 核心变更 1: Orchestrator 暂停/恢复机制 =====
public class AiOrchestrator : IAiOrchestrator
{
    private TaskCompletionSource<string>? _pauseSignal;
    private UserQuestionInfo? _currentQuestion;

    public bool IsAwaitingUserInput => _pauseSignal != null;
    public UserQuestionInfo? CurrentQuestion => _currentQuestion;

    public async IAsyncEnumerable<AiEvent> SendMessageAsync(
        string userMessage, [EnumeratorCancellation] CancellationToken ct = default)
    {
        // ... 上下文构建、发送请求 ...

        while (iteration < maxIterations)
        {
            var response = await _aiClient.SendAsync(messages, tools, ct);
            
            foreach (var block in response.Content)
            {
                if (block is TextBlock text)
                {
                    yield return new AiEvent { Type = AiEventType.StreamText, Content = text.Text };
                }
                else if (block is ToolUseBlock toolUse)
                {
                    if (toolUse.Name == "ask_user")
                    {
                        // [关键分支] 拦截 ask_user，不走 ToolExecutor
                        _currentQuestion = BuildUserQuestionInfo(toolUse);
                        yield return new AiEvent { Type = AiEventType.UserQuestion, UserQuestion = _currentQuestion };
                        yield return new AiEvent { Type = AiEventType.AwaitingUserInput };
                        
                        // 挂起等待用户输入
                        _pauseSignal = new TaskCompletionSource<string>();
                        var userAnswer = await _pauseSignal.Task;
                        
                        // 恢复：将回答作为 tool_result 返回
                        messages.Add(new ToolResultMessage(toolUse.Id, userAnswer));
                        _pauseSignal = null;
                        continue; // 继续下一轮 AI 调用
                    }
                    else
                    {
                        // 普通工具：正常执行
                        yield return new AiEvent { Type = AiEventType.ToolCall, ToolCall = BuildToolCallInfo(toolUse) };
                        var result = await _toolExecutor.ExecuteAsync(toolUse);
                        yield return new AiEvent { Type = AiEventType.ToolResult, Content = result };
                        messages.Add(new ToolResultMessage(toolUse.Id, result));
                    }
                }
            }

            if (!response.HasToolUse)
            {
                yield return new AiEvent { Type = AiEventType.Complete };
                yield break;
            }
            iteration++;
        }
    }

    public async IAsyncEnumerable<AiEvent> RespondToQuestionAsync(
        string questionId, string userResponse, 
        [EnumeratorCancellation] CancellationToken ct = default)
    {
        if (_pauseSignal == null) throw new InvalidOperationException("Not awaiting user input");
        if (_currentQuestion?.QuestionId != questionId) throw new ArgumentException("Question ID mismatch");
        
        _currentQuestion = null;
        _pauseSignal.SetResult(userResponse);
        
        // SendMessageAsync 恢复后会继续 yield 后续事件
        // 这里需要消费剩余的事件流...
        // (实际实现中可能需要一个共享 Channel 来传递事件)
        yield break; // 简化表示
    }
}
```
