# 修正指南

**focus**: 
1. 修正聊天记录点击无响应的问题
2. 将AI助手从主窗口内联面板改为右侧独立副窗口

**reason**: 
1. ListBox内部ListBoxItem拦截了MouseLeftButtonDown事件(InputBindings)，导致InputBindings无法触发
2. AI助手面板内联嵌入主窗口会遮挡浏览器内容，需要独立窗口

**deepreason**:
1. WPF中ListBox的Item容器会消费鼠标事件，导致Border上的InputBindings不触发
2. AI助手面板在主窗口中需要单独列并占用空间，浏览器全屏时仍占据MinWidth空间

**solution**:
1. 将ListBox替换为ScrollViewer+ItemsControl，条目用Button包裹以正确响应点击事件
2. 创建AiSecondaryWindow独立窗口，主窗口移除AI面板列仅保留ContentArea，通过TogglePanelCommand控制副窗口显隐

**change**:
1. `Views/AiChatPanel.xaml` Line: 79-124 — ListBox → ScrollViewer+ItemsControl+Button
2. `MainWindow.xaml` Line: 241-264 — 移除AI面板3列Grid结构，改为纯ContentArea
3. `MainWindow.xaml.cs` Line: 15-67 — 新增_aiWindow字段、Chat.PropertyChanged监听、Closing事件处理
4. `MainWindow.xaml.cs` Line: 324-371 — 新增OnChatPropertyChanged、ShowAiWindow/HideAiWindow、窗口跟随方法
5. `Views/AiSecondaryWindow.xaml` — 新建AI副窗口XAML（ToolWindow样式）
6. `Views/AiSecondaryWindow.xaml.cs` — 新建副窗口逻辑（定位、关闭/隐藏、Owner生命周期）

**keychangecode**:
```csharp
// AiChatPanel.xaml — 聊天记录改用Button确保点击
<Button Command="{Binding DataContext.LoadConversationCommand, 
    RelativeSource={RelativeSource AncestorType=UserControl}}"
    CommandParameter="{Binding Id}"
    Background="Transparent" BorderThickness="0" Cursor="Hand" Padding="6,3">
    <Button.Template>
        <ControlTemplate TargetType="Button">
            <Border Background="{TemplateBinding Background}" CornerRadius="3">
                <TextBlock Text="{Binding Preview}" Foreground="#BBB" FontSize="11"/>
            </Border>
        </ControlTemplate>
    </Button.Template>
</Button>

// MainWindow.xaml.cs — 副窗口生命周期管理
_aiWindow = new AiSecondaryWindow(this, _vm.Chat);
_aiWindow.Show();
// 主窗口关闭时
_aiWindow.AllowClose();
_aiWindow.Close();
```
